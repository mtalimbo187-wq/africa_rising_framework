🎯 THE WORKFLOW (Automated, No Manual Editing)

Script (Markdown)
    ↓
[1] RESEARCH AGENT
    └─ Extract: claims, statistics, sources, verification checklist
    ↓
[2] SCRIPT ANALYZER AGENT
    └─ Person, Place, Date, Emotion, Visual Type, Map?, Timeline?
    ↓
[3] VISUAL PLANNER AGENT
    └─ Emmy-standard strategy: Strongest visual per shot (hierarchy 10→1)
    ↓
[4] ASSET FINDER AGENT (Parallel)
    └─ Search Pexels, Pixabay, Wikimedia, NASA, Internet Archive, LoC
    ├─ Concurrent searches = Fast
    └─ Return: URLs, metadata, resolution
    ↓
[5] AI GENERATOR AGENT
    └─ Only for gaps (Veo/Runway video, Grok/DALL-E images, Maps/Timelines)
    └─ Track cost (~$5-7 per video)
    ↓
[6] TIMELINE BUILDER AGENT
    └─ Sync visuals to narration duration
    └─ Create clip timeline: 0:00–0:05 Map, 0:05–0:08 Footage, etc.
    ↓
[7] FFMPEG EDITOR AGENT
    └─ Assemble: transitions, zoom/pan, text overlays, audio mix
    └─ NO manual editing required
    └─ Output: 1280×720 MP4 @ 25fps, H.264
    ↓
[8] QUALITY REVIEW AGENT
    └─ Final QA:
       ✔ Images match narration
       ✔ Dates/timelines shown when mentioned
       ✔ Pacing 2-5 seconds per shot
       ✔ Subtitles/captions present
       ✔ Transitions smooth
       ✔ Audio/video sync perfect
    ↓
[9] PRODUCER AGENT (Reporting)
    └─ Save PROJECT_REPORT.json
    └─ Status: APPROVED or FLAG FOR REVISION
